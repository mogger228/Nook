# Проверки выпусков Nook

## Nook 1.2.0

Сборка и чистая распаковка проверены на Windows 11 23H2 x64. Пройдены 89 автоматических проверок поиска приложений, сценариев, часов, раскладок и парсера закреплений. Отдельная проверка отрисовки подтвердила смену значка батареи в обоих состояниях. Текущий статус питания считан из Windows. Физическое подключение и отключение кабеля не проверялось.

Ещё 13 проверок прошли на отдельной распакованной копии. При первом запуске перенеслись все 17 доступных закреплений. Повторный запуск сохранил изменения, а штатный выход завершил процесс. После проверки рабочая панель запущена с прежними настройками.

## Nook 0.1.0

Дата: 17 ноября 2026 года. Архив: `Nook-0.1.0-win-x64.zip`.

Сборка: C# 5, WPF, .NET Framework, x64, оптимизация `/optimize+`, версия файла 0.1.0.0. Сертификата подписи издателя нет. Архив включает девять файлов, в нём нет пользовательских настроек, сценариев, закреплений, изображений приложений, журналов, Codex или Codebase Memory.

## Реально проверенная среда

Windows 11 Pro 23H2, сборка 22631, x64; .NET Framework 4.8.1; стандартный Explorer, один монитор. Релиз полностью распакован в новую папку с пробелами и кириллицей. Использовался отдельный чистый portable-профиль, личная копия была штатно закрыта и затем восстановлена. Хэш её настроек не изменился.

## Результаты

| Проверки | Пройдено |
|---|---:|
| Поиск приложений, раскладка, полный список, выбранный результат, нижний прикреплённый островок | 19 |
| Сценарии, XML, черновики, настоящая регистрация/конфликты/освобождение Win32 hotkeys | 14 |
| Обработка Alt+F4 и перерасчёт размеров часов | 11 |
| Переходы между горизонтальной и вертикальной компоновкой | 21 |
| Парсер импорта, включая 10 000 повреждённых входов и packaged AUMID | 24 |
| Сверка встроенных настроек с оформлением профиля разработчика, без личных данных | 1 |
| Чистая установка и повторный запуск отдельной копии | 13 |
| **Всего** | **103** |

Первый запуск создал настройки рядом с exe, расположил панель снизу и импортировал **17 из 17 разрешённых записей** текущей панели Windows. Одна устаревшая/неразрешимая запись Taskband была пропущена. Скопированные ярлыки находятся только в `data/Pins` тестовой копии. При повторном запуске намеренно удалённые закрепления не появились заново; изменённый цвет сохранился, сохранённое отключение скрытия Windows соблюдалось. Штатный выход завершил процесс. В релизе готовых сценариев и пользовательских горячих клавиш нет; встроенный Alt+Пробел зарегистрировался.

Проверены PE Machine=0x8664, встроенная версия и системные зависимости: mscorlib, PresentationFramework, PresentationCore, WindowsBase, System, System.Core, System.Drawing, System.Xml. Абсолютный путь рабочего проекта в бинарнике не обнаружен. Автоматическая упаковка использует явный список файлов; SHA-256 находится в отдельном `.sha256` рядом с архивом.

Проведено отдельное статическое ревью: исправлены пропуск прямых exe и коротких packaged-идентификаторов, разные пути данных у команд восстановления, сохранение режима скрытия Windows и конфликт legacy `--replace` с сохранённой настройкой. После исправлений блокирующих замечаний не осталось.

## Что не проверялось

Другие сборки Windows, Windows ARM64, Windows 10, несколько мониторов, чистая машина только с .NET 4.8, RDP, сторонние оболочки и корпоративные ограничения. Доступность системных API проверена по документации; это не заменяет запуск на этих системах. Не проводились длительный тест утечек, новая перезагрузка Windows для проверки автозапуска и проверка запуска каждого импортированного приложения.

Поддержка и ограничения описаны в `COMPATIBILITY.md` внутри ZIP. Для первого публичного размещения рекомендуется отметить выпуск на GitHub как предварительный, пока пользователи не подтвердят дополнительные версии Windows. Публичная лицензия исходного кода владельцем ещё не выбрана.
