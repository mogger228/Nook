# Совместимость Nook 1.2.0

## Целевая конфигурация

Windows 11 x64 с обычной оболочкой Explorer, один монитор, .NET Framework 4.8 или 4.8.1. Сборка нативного исполняемого файла — x64, управляемый код — C# 5 / WPF. Используются только системные библиотеки Windows/.NET.

| Система | Статус |
|---|---|
| Windows 11 Pro 23H2, сборка 22631, x64, .NET 4.8.1 | Реально доступная тестовая машина; результаты текущего выпуска перечислены ниже |
| Windows 11 21H2/22H2 x64 | Проверка доступности API по документации, без запуска на отдельной системе |
| Более новые сборки Windows 11 x64 | Не тестировались; возможны изменения Explorer и формата закреплений |
| .NET Framework 4.8 | Целевой runtime; отдельное испытание на машине только с 4.8 не проводилось |
| Windows 10 и более старые версии | Не поддерживаются этим выпуском; проверка версии до создания панели |
| Windows ARM64, эмуляция x64 | Не проверялось и не заявляется поддержка |
| Windows x86 / Linux / macOS | Не поддерживаются |
| Несколько мониторов, RDP, заменённый Explorer | Не проверялись и не входят в целевую конфигурацию |

## Границы системных интеграций

- Импорт использует чтение Taskband и системные Shell API. Taskband — недокументированный формат; неизвестные записи не передаются как указатели в Shell. Формат сначала полностью проверяется, при отказе используется папка ярлыков. Порядок и полнота импорта зависят от версии Windows.
- Часы рабочего стола используют дочерние поверхности Explorer. При неизвестной структуре рабочего стола часы могут быть недоступны; совместимость с будущими версиями Explorer не гарантируется.
- Стеклянное оформление настроек запрашивается через DWM; при отказе применяется обычный тёмный фон. Фон панели — прозрачный цвет, без настоящего blur.
- Перенос/резерв места панели использует AppBar и временное состояние автоскрытия Explorer. Исходное состояние сохраняется до изменения; при аварии используйте Restore-Taskbar.cmd.
- «Завершить задачу» ограничено проверкой идентичности процессов и отказывает для защищённых/общих системных процессов. Не даёт гарантию остановки всех типов приложений.
- Поведение UAC, защищённых рабочих столов, корпоративных ограничений и сторонних модификаций панели не проверено.

## Проверки выпуска

Результаты реального первого запуска, повторного запуска и тестов фиксируются в отдельном `RELEASE-CHECKS.md` рядом с архивом на GitHub. Упоминание API выше не является заявлением о проведённом испытании другой ОС.
