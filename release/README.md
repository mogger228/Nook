# Nook 1.2.0

Компактная панель приложений для Windows 11 x64: закрепления, часы, индикаторы, поиск и сценарии запуска.

## Запуск

1. Полностью распакуйте ZIP в отдельную папку, доступную для записи, например в «Документы». Не запускайте программу внутри архива. Не используйте Program Files или системные папки.
2. Откройте `Nook.exe` или `Start-Nook.cmd`. Установка, права администратора, Codex, Python, Node.js и SDK не нужны. Требуется системный .NET Framework 4.8 или 4.8.1.
3. На первом запуске Nook располагается снизу и скрывает обычную панель Windows. Закрепления текущего пользователя импортируются автоматически. При неизвестном формате Windows используется папка закреплённых ярлыков; часть приложений и исходный порядок могут быть недоступны. Результат импорта виден в настройках часов/островков. Повторный запуск не заменяет ваши закрепления.

Откройте «⋯ → Настройки Nook», чтобы изменить положение, цвета, размеры и автозапуск. При первом запуске автозапуск не включается. Настройки, скопированные ярлыки и журналы сохраняются рядом с exe в папке `data`. Сохраняйте её при обновлении. Для переноса на другой компьютер лучше использовать чистый архив: пути к программам, сценариям и ярлыкам привязаны к конкретной системе.

## Поиск и сценарии

- `Alt + Пробел`: поиск приложений меню «Пуск» и закреплений; поддерживается ошибочная русско-английская раскладка.
- ↑/↓ выбирают результат, Enter запускает, Esc закрывает. Одновременно видны три результата, остальные доступны прокруткой.
- `Ctrl + Alt + Пробел` открывает веб-поиск. В его настройках можно выбрать Google или Яндекс, браузер и оформление. Подсказки отправляют текст поисковику по мере ввода. Их можно отключить.
- Молния внутри значка батареи означает, что ноутбук подключён к сети. Подсказка показывает, идёт ли зарядка.
- Во вкладке «Сценарии» можно настроить приложения, проекты, сайты и собственные горячие клавиши. Готовых личных сценариев в архиве нет.
- Если сочетание занято другой программой, Nook сообщит об этом в настройках соответствующей функции.

## Выход и восстановление Windows

«⋯ → Выйти» закрывает Nook и возвращает панель Windows. При аварии запустите `Restore-Taskbar.cmd` из той же распакованной папки. Если Nook продолжает работать, команда также отключает скрытие в его настройках. Alt+F4 намеренно не закрывает саму панель. После принудительного завершения процесса обработчики выхода выполнить невозможно, поэтому сохранённое состояние Explorer восстанавливает отдельная команда.

Для обновления выйдите из Nook, распакуйте новую версию в ту же папку с заменой файлов программы, сохранив `data`. Не перемещайте включённую в автозапуск копию без последующего выключения и повторного включения автозапуска. Удаление: выключите автозапуск, выйдите из Nook и удалите папку. Никакие службы или драйверы не устанавливаются.

## Важные ограничения

Проверенная система и непроверенные конфигурации перечислены в `COMPATIBILITY.md`. Полный трей Windows не заменён; чтобы увидеть все фоновые значки, верните штатную панель через меню. Настоящее размытие фона панели пока отключено; используется прозрачный цвет. Погода показывает Санкт-Петербург и запрашивается у Open-Meteo: при этом сервис получает обычный сетевой запрос и IP-адрес. Погоду можно отключить в настройках. Для остальной работы сеть не требуется.

Сборка не подписана сертификатом издателя; Windows может показывать предупреждение о неизвестном приложении. Не отключайте защиту Windows. Сравните SHA-256 архива с файлом `.sha256`, опубликованным рядом с релизом.

Правовые сведения и внешние компоненты: `THIRD-PARTY-NOTICES.txt`. Пакет не содержит исходного кода, инструментов разработки, персональных закреплений, сценариев и истории разработчика.
